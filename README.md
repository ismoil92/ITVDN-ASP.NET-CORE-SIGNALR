# ITVDN-ASP.NET-CORE-SIGNALR

### Тема: Практика номер 4. Пользователи и группы в SignalR Core.

*Задание*
  1. Создайте клиент-серверную систему с использованием .NET (WPF) и JS клиентов. Реализуйте возможность группировки отдельно .NET (WPF) клиентов и отдельно JS. Сделайте возможность передачи сообщений как между участниками одной группы, так и между всеми по выбору клиента, который при пересылке указывает кто должен видеть эти сообщения.
  2. Модифицируйте код первого задания, добавив возможность задания имени пользователя, реализовав собственный провайдер пользователей и показа имени пользователя в передаваемых сообщениях.
  3. Реализуйте возможность создавать приватные чат комнаты, в которой могут быть только уникальный пользователи. К чат комнате могут подключиться только по её имени. Если пользователь передает сообщение, то все другие пользователи комнаты видят его имя. Подключения этого же пользователя видят в качестве имени “Me”.
